# Rituel hebdomadaire RéussiMaths — 1 à 2 heures

Objectif : maintenir la fiabilité commerciale et améliorer réellement les apprentissages sans transformer RéussiMaths en second emploi.

## Les 60 premières minutes — indispensables

1. **10 min — Santé commerciale et technique**
   - vérifier les paiements et les webhooks Stripe en erreur ;
   - vérifier les erreurs Vercel et les messages reçus ;
   - traiter immédiatement tout blocage de connexion, paiement ou accès acheté.
2. **15 min — Retours utilisateurs**
   - regrouper les retours identiques ;
   - classer : bloquant, erreur pédagogique, incompréhension, amélioration ;
   - ne retenir qu'un problème prioritaire pour la semaine.
3. **25 min — Audit pédagogique ciblé**
   - ouvrir le laboratoire des corrections ;
   - commencer par la file « Découverte à traiter », puis les corrections sous 9/10 ;
   - noter 3 à 5 corrections, compléter la grille et écrire une remarque précise ;
   - privilégier une même famille pédagogique afin qu'une réécriture améliore plusieurs exercices.
4. **10 min — Décision et traçabilité**
   - copier le bilan d'apprentissage pour Codex ;
   - choisir une seule correction globale ou un seul correctif technique ;
   - noter ce qui attend la semaine suivante.

## Les 60 minutes supplémentaires — si disponibles

1. Faire modifier par Codex la famille de corrections prioritaire.
2. Contrôler trois exemples représentatifs avant/après.
3. Lancer les tests et l'audit automatique.
4. Faire un seul commit clairement nommé et vérifier le déploiement Vercel.

## Ordre de priorité permanent

1. Paiement encaissé mais accès absent.
2. Erreur mathématique ou correction trompeuse.
3. Parcours Découverte inférieur à 9/10.
4. Saisie impossible ou affichage illisible.
5. Problème récurrent signalé par plusieurs utilisateurs.
6. Amélioration de confort ou nouvelle fonctionnalité.

## Règles anti-dispersion

- Une semaine = un problème principal résolu proprement.
- Une nouvelle fonctionnalité attend si un problème bloquant ou pédagogique reste ouvert.
- Toute amélioration d'une correction doit être appliquée à sa famille entière lorsque la règle est commune.
- Les parcours Découverte sont examinés avant les contenus payants moins consultés : ils déterminent la confiance et la conversion.
- Le laboratoire, les tests et les retours utilisateurs constituent la liste de travail ; ne pas maintenir une deuxième liste parallèle.
